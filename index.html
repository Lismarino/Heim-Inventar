Einstellungen

Sicherung

Sichert alles: Einträge, Kategorien, Orte, Räume, Archiv und Fotos in einer Datei. Der API-Key wird aus Sicherheitsgründen nicht mitgesichert.

Google Gemini API

Kostenlosen API-Key besorgen – Anleitung
  1. Öffne aistudio.google.com/app/apikey im Browser.
  2. Mit deinem Google-Konto anmelden.
  3. Auf Create API key tippen und ein Projekt wählen (oder neu anlegen lassen).
  4. Der Key beginnt mit AIza… – kopieren.
  5. Hier oben in das Feld API-Key einfügen. Er wird nur auf diesem Gerät gespeichert.

Google AI Studio hat ein kostenloses Kontingent, das für gelegentliches Foto-Erkennen locker reicht. Der Key liegt unverschlüsselt in der lokalen Datenbank dieser App – wer dein entsperrtes Gerät hat, kann ihn auslesen. Bei Verdacht: Key in AI Studio löschen und neu erstellen.

Über

Alle Einträge und Fotos liegen ausschließlich in der lokalen Datenbank dieses Geräts (IndexedDB). Es gibt keinen Server und kein Konto. Nur die Bilderkennung schickt das jeweilige Foto an Google Gemini.

Die Daten hängen an dieser Web-Adresse und an dieser Installation. Sie gehen verloren, wenn du die App vom Home-Bildschirm löschst, in Safari die Website-Daten löschst oder die App unter einer anderen Adresse aufrufst. Mach dir deshalb regelmäßig eine Sicherung.

KI-Erkennung

Mit einem kostenlosen Schlüssel von Google benennt die App deine Fotos von selbst – „Akkuschrauber“, „Pfanne“, „Wintermantel“.

  1. aistudio.google.com/app/apikey öffnen und mit dem Google-Konto anmelden
  2. Create API key tippen und den Key kopieren
  3. Hier einfügen – er bleibt nur auf diesem Gerät

Ohne Key funktioniert alles – Namen tippst du dann selbst. Nachtragen geht jederzeit in den Einstellungen.
