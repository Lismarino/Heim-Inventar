Einstellungen

Google Gemini API

Kostenlosen API-Key besorgen – Anleitung
  1. Öffne aistudio.google.com/app/apikey im Browser.
  2. Mit deinem Google-Konto anmelden.
  3. Auf Create API key tippen und ein Projekt wählen (oder neu anlegen lassen).
  4. Der Key beginnt mit AIza… – kopieren.
  5. Hier oben in das Feld API-Key einfügen. Er wird nur auf diesem Gerät gespeichert.

Google AI Studio hat ein kostenloses Kontingent, das für gelegentliches Foto-Erkennen locker reicht. Der Key liegt unverschlüsselt in der lokalen Datenbank dieser App – wer dein entsperrtes Gerät hat, kann ihn auslesen. Bei Verdacht: Key in AI Studio löschen und neu erstellen.

Über

Alle Einträge und Fotos liegen ausschließlich in der lokalen Datenbank dieses Geräts (IndexedDB). Es gibt keinen Server und kein Konto. Nur die Bilderkennung schickt das jeweilige Foto an Google Gemini.

Noch kein Export: Sicherung und Übertragung auf ein anderes Gerät kommen im nächsten Schritt. Bis dahin: die App nicht vom Home-Bildschirm löschen und in Safari nicht die Website-Daten löschen.
